Which statistic answers which question?

Quick reference

Mean (x̄): the central value that represents your replicates.

Standard deviation (s): the spread around the mean. The calculator uses the sample SD (divided by n − 1).

CV% = s / x̄ × 100: the relative spread, also reported as %RSD (relative standard deviation), especially in pharmaceutical work. Because it has no units, it lets you compare methods. As a rough guide: below 2 % excellent, below 5 % acceptable, above 10 % worth investigating.

SEM = s / √n: the standard error of the mean. It tells you how well you know the true mean.

95 % CI = x̄ ± t × SEM: the confidence interval for the mean, with Student's t for n − 1 degrees of freedom. If you repeated the whole experiment many times, 95 % of the intervals built this way would contain the true mean.

Outlier detection

An outlier is a value that lies unusually far from the rest of the data set. A statistical test only tells you that a value is suspicious; before removing it, always look for an assignable cause, such as a transcription error, an instrument fault or a contaminated sample.

Grubbs' test (ISO 5725-2) — used for n > 10

G = max |xᵢ − x̄| / s

If G > Gcrit (α = 0.05, two-sided), the most extreme value is a statistically significant outlier. Grubbs' test assumes the data are approximately normally distributed and tests one suspect value at a time.

Dixon's Q test — used for n ≤ 10

Q = |xsuspect − xnearest| / range

If Q > Qcrit, the extreme value is an outlier. Because it only uses the gap to the nearest value and the range, it suits the small sets of replicates that are typical in the lab.

Frequently asked questions

Should I use Grubbs' test or Dixon's Q test?

Dixon's Q test only looks at the gap between the suspect value and its nearest neighbor, so it works with very small data sets (3 to 10 values). Grubbs' test uses the mean and the standard deviation of the whole set and is the test recommended by ISO 5725-2; it becomes more reliable as n grows. The calculator chooses automatically: Dixon's Q test for n ≤ 10 and Grubbs' test for n > 10.

Can I remove an outlier and recalculate?

Only if you can justify the cause, such as a recorded pipetting error or a documented instrument failure. Removing a value on statistical grounds alone, with no physical explanation, is not accepted for methods accredited to ISO/IEC 17025. If you remove a value, document it in the report.

Why divide by n − 1 instead of n?

Because your measurements are a sample (a subset) of all the measurements you could make, not the whole population. Dividing by n − 1 instead of n corrects the bias and gives a better estimate of the true variability of the method.
